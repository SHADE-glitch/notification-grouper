## 规范偏差
- `check:log` 的覆盖窗口不含 schema/metadata（CODE_PATHS 只有 4 个 js），而 AGENTS 把 schema 键当 public API。
- README 的"四个开关"名不副实（2 个开关 + 1 个数值 + 1 个名单）。
- README 少写一路守卫（只说 `_pending` 带 sender pid，实际还带 `params[0]`）。
- fixture 的出处声明超出数据（每个 fixture 只含一个 pid）。
- "记录里不许出现真实应用名"的守卫是封闭词表，覆盖面有限 —— 按约定不计为缺陷，仅记录。
